# JDOM SITE

## Le Portail National des Données Ouvertes du Mali

JDOM (Jeux de Données Ouvertes du Mali) est le portail national centralisé pour la publication et la consultation de données ouvertes. Notre mission est de créer un écosystème numérique transparent, accessible et innovant qui favorise le développement socio-économique du Mali.

## 🎯 Vision

En centralisant, normalisant et libérant les données publiques, nous ouvrons de nouvelles perspectives pour les citoyens, les entreprises et les institutions. Ensemble, construisons un Mali numérique fondé sur la transparence et l'innovation.

## ✨ Technologies Utilisées

- **⚡ Next.js 16** - Framework React pour la production avec App Router
- **📘 TypeScript 5** - JavaScript typé pour une meilleure expérience développeur
- **🎨 Tailwind CSS 4** - Framework CSS utility-first pour le développement UI rapide
- **🧩 shadcn/ui** - Composants UI de haute qualité et accessibles
- **🎯 Lucide React** - Bibliothèque d'icônes moderne

## 🚀 Démarrage Rapide

```bash
# Installer les dépendances
npm install

# Démarrer le serveur de développement
npm run dev

# Construire pour la production
npm run build

# Démarrer le serveur de production
npm start
```

Ouvrez [http://localhost:3000](http://localhost:3000) pour voir l'application en cours d'exécution.

## 📁 Structure du Projet

## 🎯 Objectifs

- **Catalogue National** - Base de données centralisée et structurée de toutes les données publiques maliennes
- **Accès Libre** - Téléchargement gratuit et accès API pour tous

- **Innovation & Économie** - Stimuler l'innovation numérique et créer des opportunités économiques
